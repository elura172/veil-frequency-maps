# Mirror Hands

Mirror Hands is the six-lane Max nervous system for the Mirror Voice Engine. It listens on UDP `9000`, smooths each normalized quality into a signal with `line~`, and owns mapped Live parameters through `live.remote~ @normalized 1`.

Mapping protocol:

```text
/mirror/hands/map <quality> <track> <device> <parameter>
/mirror/hands/unmap <quality>
/mirror/hands/unmap_all
/mirror/hands/smoothing <quality> <milliseconds>
/mirror/hands/status
```

Replies use UDP `9001`. All indices are zero-based. The six mapping LEDs show successful `live.remote~` ownership. Removing the device releases every target with `id 0`.

The `.maxpat` is generated by `scripts/build_mirror_hands.py`; the `.amxd` is then packaged deterministically.
