# Mirror Ensemble

The expressive Mirror instrument is a three-layer, project-agnostic topology.
It replaces the original single-Operator audition without changing the six
canonical qualities or OSC protocol.

## Layers

1. **Body** — low Operator foundation followed by Mirror Hands.
2. **Veil** — Wavetable with restrained Chorus-Ensemble and Reverb.
3. **Reflection** — high Operator through Saturator, Auto Pan-Tremolo, and Auto Filter.

Each layer uses a quiet sixteen-beat sustained note for auditioning. These are
test sources, not composition material.

## Semantic ownership

| Quality | Target | Musical role |
| --- | --- | --- |
| energy | Body / Operator / Tone | harmonic intensity without muting silence |
| brightness | Veil / Wavetable / Flt 1 Freq | spectral opening |
| warmth | Body / Operator / Filter Res | roundness and resonance |
| shimmer | Veil / Wavetable / Osc 1 Pos | wavetable color |
| motion | Reflection / Auto Pan-Tremolo / Amount | spatial movement |
| density | Veil / Wavetable / Osc 2 Gain | transposed harmonic layering |

Veil volume is fixed at a restrained audible level. Density must not own layer
volume: doing so caused quiet acoustic frames to erase the palette. Spoken
semantics persist between acoustic frames and lead with semantic weight `0.8`;
microphone features shade rather than reset the last understood phrase.

For live microphone use, use an isolated headset microphone or headphones.
Open speakers can be re-transcribed as repeated short phrases and create a
semantic feedback loop.
